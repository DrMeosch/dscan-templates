# AGENTS.md

This repository is DSCAN's fork of [projectdiscovery/nuclei-templates](https://github.com/projectdiscovery/nuclei-templates): the nuclei templates the DSCAN scanner runs. For the system picture see the ARCHITECTURE.md of the DSCAN backend.

## Layout

- `http/`, `dns/`, `ssl/`, `network/`, `cloud/`, `javascript/`: upstream templates by protocol.
- `helpers/`: payloads and wordlists that templates reference.
- `profiles/`: nuclei scan profiles.
- `local/`: community templates fetched by `.github/download-prs.py` from upstream PRs that were open at the time. The rsync never overwrites or deletes it.
- `scripts/`: `check_changelog.py` (the Changelog check) and `changelog_feed.py` (the Changelog issue feed), with their `test_*.py`. The sync leaves it alone.
- `.github/pull_request_template.md`, `.github/workflows/changelog.yml`, `.github/workflows/changelog-feed.yml`: the PR template and the Changelog check and feed workflows. The upstream root `PULL_REQUEST_TEMPLATE.md` is removed and excluded from the sync.
- `.github/workflows/sync.yml`: the Sync workflow. `.github/download-prs.py` pulls in open upstream PRs; `.github/remove-blacklisted.py` drops templates DSCAN blacklists (its `BLACKLISTED_LIST`).
- `cves.json`, `*-checksum.txt`, `TEMPLATES-STATS.*`, `contributors.json`: generated by the sync. Do not edit them by hand.

## Build and test

There is no build. Two checks exist. The template check is the one Sync runs, with nuclei v3.11.1 installed (it is not installed in the default agent environment):

    nuclei -duc -validate -t "$(pwd)"

Changelog scripts: `PYTHONPATH=scripts python3 -m unittest test_check_changelog test_changelog_feed`. CI runs the same, then `python3 scripts/check_changelog.py` on the PR body.

Sync also runs `python .github/download-prs.py` and `python .github/remove-blacklisted.py -t .`. Both rewrite the tree and need `requests` and `pyyaml`, so run them only in a scratch copy.

## Rules

- Everything outside `local/`, `.github/`, `scripts/`, `AGENTS.md`, `README.md` and `.gitignore` is mirrored from upstream by Sync (`rsync --delete`; its `--exclude` list in `sync.yml` is authoritative, and it also keeps the upstream root `PULL_REQUEST_TEMPLATE.md` out). A manual edit to a mirrored file is lost on the next sync; change DSCAN-specific behaviour in `local/` or the blacklist instead.
- Sync stays enabled. Each `[autosync]` PR is reviewed and merged on the owner's word; never close one.
- A template must pass `nuclei -validate` before it merges.
- Do not edit generated files or `CHANGELOG.md` files.
- Every PR body needs a `## Changelog` section: one or two user-facing lines (Added/Changed/Fixed/Removed/Security), or `none` for internal-only changes. The Changelog check fails a PR without it; bot and `sync-nuclei-templates-*` autosync PRs are exempt. Merged PRs are appended to the pinned `Changelog` issue. There is no `CHANGELOG.md`.
